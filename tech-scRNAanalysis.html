Macrophage-Endothelial Immunoregulatory Axis in Septic AKI
Privratsky et al. (2023) Kidney Int · GEO: GSE298053 · CLP 小鼠肾脏
📊 Seurat🔬 scRNA-seq🧪 NicheNet🧬 F4/80hi🩸 IL-6🧫 Il1rn

1 项目背景

🎯 研究问题

脓毒症是 ICU 中急性肾损伤（AKI）最常见的病因，死亡率 >50%。肾脏巨噬细胞发挥保护作用，但哪个亚群、什么机制不明确。

📋 实验设计
  • 模型：CLP 诱导脓毒症
  • 样本：小鼠肾脏，Sham vs CLP 24h
  • QC 后：18,055 细胞，22,399 基因
💡
关键概念：scRNA-seq 能在单细胞分辨率下测量基因表达，区分"哪个细胞类型"在"什么条件"下表达"哪个基因"。

2 数据加载与预处理

使用 Read10X 读取 10X Genomics 标准输出，加后缀 --C0 / --C24 后合并。

# 加载数据
library(Seurat)
c0 <- Read10X(data.dir = "dataset/0/")
c24 <- Read10X(data.dir = "dataset/24/")
colnames(c0) <- paste0(colnames(c0), "--C0")
colnames(c24) <- paste0(colnames(c24), "--C24")
experiment.data <- cbind(c0, c24)
experiment.aggregate <- CreateSeuratObject(
  experiment.data, project = "ShamCLP",
  names.field = 2, names.delim = "\\\\-\\\\-")
# 标记 Sham / CLP24
samplename <- experiment.aggregate$orig.ident
sample.id <- ifelse(samplename == "C24", "CLP24", "Sham")
experiment.aggregate <- AddMetaData(experiment.aggregate, sample.id, col.name = "group")
table(experiment.aggregate$group)

图 1 | QC 过滤前后的线粒体比例分布。红线 = 55% 阈值。
# 线粒体比例 + scater 双重过滤
experiment.aggregate[["percent.mt"]] <- PercentageFeatureSet(
  experiment.aggregate, pattern = "^mt-")
experiment.aggregate.sce <- as.SingleCellExperiment(experiment.aggregate)
per.cell <- perCellQCMetrics(experiment.aggregate.sce,
  subsets = list(Mito = grep("^mt-", rownames(experiment.aggregate.sce))))
filter_by_expr_features <- per.cell$detected >= 200 & per.cell$detected <= 9000
filter_by_total_counts  <- per.cell$sum >= 500 & per.cell$sum < 150000
filter_by_MT            <- per.cell$subsets_Mito_percent <= 55
experiment.aggregate.sce$use <- filter_by_expr_features & filter_by_total_counts & filter_by_MT
table(experiment.aggregate.sce$use)  # 18,055 cells
⚠️
注意：原始脚本缺少 nFeature ≤ 9000 上限，已补充。

4 标准化与整合

按样本拆分后分别 LogNormalize，各选 2000 个高变基因，锚点法消除批次效应。

# 拆分 → 归一化 → 高变基因 → 锚点整合
list <- SplitObject(filtered, split.by = "group")
list <- lapply(list, function(x) {
  x <- NormalizeData(x)
  x <- FindVariableFeatures(x, nfeatures = 2000)
})
anchors <- FindIntegrationAnchors(object.list = list, dims = 1:20)
integrated <- IntegrateData(anchorset = anchors, dims = 1:20)
integrated <- ScaleData(integrated)  # 不回归变量

5 PCA 降维与评估

🧠 为什么需要 PCA？

~20,000 个基因维度中信号集中在前几个主成分。PCA 就像"用 50 个关键词概括一本 20,000 页的书"，去除噪音。

📊 JackStraw 原理

通过 100 次置换检验比较真实 PC vs 随机 PC 的载荷，判断哪些 PC 有统计显著性。

# PCA + JackStraw
integrated <- RunPCA(integrated, npcs = 50)
integrated <- JackStraw(integrated, num.replicate = 100, dims = 50)
JackStrawPlot(integrated, dims = 1:50)
ElbowPlot(integrated, ndims = 50)

6 UMAP 降维与聚类

论文系统扫描分辨率 0~3（步长 0.1），clustree 评估稳定性，最终选 res=0.5（23 个簇）。

图 2 | UMAP 降维后的 23 个细胞簇。res=0.5，Louvain 算法。
# UMAP + 多分辨率聚类
integrated <- RunUMAP(integrated, dims = 1:50)
integrated <- FindNeighbors(integrated, dims = 1:50)
for (i in seq(0, 3, 0.1)) {
  integrated <- FindClusters(integrated, resolution = i, verbose = FALSE)
}

8 巨噬细胞提取与亚聚类

提取簇 7，切换 RNA assay，按样本拆分后重新整合后重聚类。

图 5 | 巨噬细胞 4 亚群：F4/80hi、CD11bhi、cDC2、Transition。
# 提取 → 重新整合 → 重聚类
macro <- subset(integrated, idents = "7")
DefaultAssay(macro) <- "RNA"
macro.list <- SplitObject(macro, split.by = "group")
macro.list <- lapply(macro.list, function(x) { x <- NormalizeData(x); FindVariableFeatures(x, nfeatures = 2000) })
anchors <- FindIntegrationAnchors(object.list = macro.list, dims = 1:30)
macro.integrated <- IntegrateData(anchorset = anchors, dims = 1:30)
macro.integrated <- ScaleData(macro.integrated)
macro.integrated <- RunPCA(macro.integrated, npcs = 30)
macro.integrated <- RunUMAP(macro.integrated, dims = 1:20)
macro.integrated <- FindNeighbors(macro.integrated, dims = 1:20)
for (i in seq(0, 2, 0.1)) macro.integrated <- FindClusters(macro.integrated, resolution = i, verbose = FALSE)
